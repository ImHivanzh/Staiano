# Vista cliente

Mode: Experience. Established Staiano visual system; code-led extension.

## Direction contract

THESIS: The customer watches the actual project while the operator continues editing in another window.

OWN-WORLD: Existing Staiano logo, Inter, white header and footer, existing Three.js materials and cutaway model. No editor rail, forms, catalogues or technical configuration menus.

STORY: “Apri vista cliente” opens a separate window on the same computer/browser, suitable for a connected TV. Project changes and active-floor changes update immediately. Undo and redo follow the operator. The client camera remains independent.

FIRST VIEWPORT: Compact logo/project header, live connection status and fullscreen action. The model occupies the remaining space. Footer identifies the floor and separate installations. At 1920×1080 and 1024×768, controls fit without horizontal overflow.

FORM: Expand the established model view; no new visual identity or generated assets. Native BroadcastChannel carries a private session snapshot without attachments or source drawings. Client page never loads the repository or saves changes.

FINISH: Review the customer windows and grille selection at desktop/iPad sizes; verify synchronization, popup reopening, disconnect, and the existing compact configuration layout.
